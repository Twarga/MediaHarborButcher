# Code of Conduct

## Our standards

This project follows a simplified version of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**Expected behavior:**

- Be respectful in issues, pull requests, and discussions.
- Assume good faith; people work in different time zones and contexts.
- Focus critique on code and ideas, not people.
- Credit prior work and collaborators.

**Not tolerated:**

- Personal attacks, harassment, discriminatory comments.
- Publishing others' private information without consent.
- Off-topic trolling or spam.

## Scope

Applies to all project spaces — issues, pull requests, code comments, the
repository README, and any official communication channels.

## Enforcement

Maintainers may delete comments, close issues, or block contributors who
don't meet these standards. Serious or repeated violations can result in a
permanent ban.

Report issues to **twarga@users.noreply.github.com**. Reports will be
reviewed privately and promptly.
