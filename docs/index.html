Everything you need

🌐

Any Website

Works on JavaScript-heavy sites, infinite scroll, lazy loading, and single-page apps.

🎬

Images & Videos

JPG, PNG, WebP, GIF, MP4, WebM, and HLS/DASH streams converted to MP4 via ffmpeg.

✅

Select & Download

Preview every found file in a grid. Check what you want, uncheck what you don't.

⚡

Real-time Progress

Live log as the scan runs. Download progress bar with speed and ETA.

🛡️

Stealth Mode

Playwright stealth bypasses bot detection on sites that block automated browsers.

⚙️

Full Control

Set output folder, subfolders, min image size, formats, concurrency, scroll depth.

🗂️

Organized Output

Auto-creates per-site folders. Separate images/ and videos/ subfolders. MD5 dedup.

📋

Harvest History

Every harvest saved to local SQLite. One-click to open the output folder.

🔒

100% Local

No accounts, no cloud, no telemetry. Everything runs on your machine.

How it works

1

Paste URL

Drop any webpage URL into the input field.

2

Scan

Real browser loads the page, scrolls, and finds all media.

3

Select

Preview the grid. Pick exactly what you want to keep.

4

Download

Files saved to your configured folder. Done.

Get started

Runs locally. No Docker, no cloud, no accounts.

# Clone the repo
git clone https://github.com/Twarga/MediaHarborButcher.git
cd MediaHarborButcher
 
# Install everything
chmod +x install.sh && ./install.sh
 
# Run
./run.sh
 
# Open in browser
http://localhost:8000
Python 3.11+ Node.js 18+ ffmpeg (optional) Linux / macOS / Windows
