What's inside

A harvester that actually works.

MediaHarbor doesn't just curl URLs. It opens a real browser, forwards cookies, retries with backoff, and hands the hard videos to yt-dlp.

Smart video engine

Powered by yt-dlp. Automatic fallback on 1800+ sites — TikTok, Instagram, Twitter, Vimeo, Reddit, Twitch. Reassembles HLS/DASH streams into clean MP4.

Cookies forwarded

Playwright cookies and Referer are reused for every download, so CDN-protected media works without a separate login step.

Retry & recover

Auto-retry with exponential backoff on 403/429/5xx. Content-Type validation. One-click "retry failed" after each batch.

Real-time scan

Live log of what the browser finds. Grid fills in as files are discovered. Keyboard shortcuts for the impatient.

Stealth mode

Playwright stealth bypasses bot detection on sites that block automated browsers. Realistic headers out of the box.

Organized output

Auto-creates per-site folders. Separate images/ and videos/ subfolders. MD5 dedup.

Harvest history

Every session saved to local SQLite. Search, open output folder, retry failed downloads — all without leaving the app.

Full control

Output folder, min image size, allowed formats, concurrency, scroll depth. Tweak every knob without leaving the browser.

100% local

No accounts, no cloud, no telemetry. Runs on your machine, downloads to your disk. Your URLs never leave.

Workflow

Four steps. No learning curve.

From "I want that video" to "it's in my downloads folder" in under a minute.

Paste URL

Drop any webpage link into the input field and pick Auto or Select mode.

Live scan

A real browser loads the page, scrolls, and reports every image and video it sees.

Preview grid

See thumbnails for everything found. Pick what you want, uncheck what you don't.

Download

Files land in your configured folder, organized, deduped, and renamed. Retry-failed is one click away.

Install

Runs locally. No Docker, no cloud.

One script installs everything. One script starts it. Then paste URLs and harvest.

# Clone
git clone https://github.com/Twarga/MediaHarborButcher.git
cd MediaHarborButcher
 
# Install
chmod +x install.sh && ./install.sh
 
# Run
./run.sh
 
# Open
http://localhost:8000
